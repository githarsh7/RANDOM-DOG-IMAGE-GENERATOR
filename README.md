# 🐶 Random Doggo Generator

A simple and fun web app that fetches and displays random dog images using the Dog CEO API. Built with HTML, CSS, and JavaScript, this project lets users enjoy adorable doggos at the click of a button.

---

## 🚀 Features
- 🐕 Fetch random dog images instantly
- 🎯 Simple and clean UI
- ⚡ Fast and lightweight
- 🔁 Generate a new dog image with one click

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (Fetch API)

---

## 📸 How It Works
1. Click on the **"Get Random Doggo!"** button  
2. The app fetches a random image from the Dog CEO API  
3. The image updates instantly on the screen
